How interest is scored

DOI(x) = API(x) − D(x, focus)

API, the a-priori importance, is minus the depth: the kingdom scores 0, a species −5, so taxa near the root matter more by default. D is the number of edges between the node and the focus.

A node is drawn when DOI(x) ≥ DOI(focus) − k. Every ancestor of the focus ties with it, so the path to the root stays visible. Siblings always tie too, so a node's children appear or disappear together.

k moves in steps of 2 because every DOI has the same odd or even parity as the focus's; odd values would change nothing.
